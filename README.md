# EonSurf

Navegador web nativo para PlayStation 3 (homebrew, PS3HEN), basado en el motor [NetSurf](https://www.netsurf-browser.org/).

- HTTPS moderno (curl + mbedTLS), CSS moderno y JavaScript (QuickJS).
- Manejable con el DualShock 3. Interfaz en español e inglés.
- Se instala como .pkg y aparece en la columna Juego.

Estado: **en desarrollo**, nada probado en una PS3 real todavía.
La especificación completa está en [docs/ESPECIFICACION.md](docs/ESPECIFICACION.md).
